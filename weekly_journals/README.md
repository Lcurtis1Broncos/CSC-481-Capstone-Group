# Weekly Journals

Each team member should add one journal per week, from Week 2 through Week 15.
Follow the established naming format: `YYYY-MM-DD_firstname_lastname.md`, using
the reporting period's ending date.

- [Reusable Lucas journal template](TEMPLATE_lucas_curtis.md)
- [Week 12 Lucas journal starter](2026-11-08_lucas_curtis.md)

Copy the template into a new dated file for each week. Fill in actual personal
work, expected/observed test results, lessons, problems, next steps, and evidence.
Use concise action-led entries such as "Used," "Tested," and "Documented,"
with first-person wording where natural. Remove all bracketed prompts before
marking the journal Complete. Do not overwrite the reusable template each week.
