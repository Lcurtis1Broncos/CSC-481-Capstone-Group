# Week 8 Evidence

This folder records data-run parsing and the controlled slack-space experiment.
The JSON payload manifest is generated by `code/slack_embed.py` and includes
the source hash, working-image hash, exact location, marker, byte length,
payload hash, original overwritten slack bytes, and verification result.

The source and working `.dd` files remain local and are excluded from Git.

## Controlled result on October 8

- Host: `Testfile.docx`, MFT record 41.
- Final-cluster slack: 2,947 bytes beginning at image offset 16,049,277.
- Marker: `TEAM3_SLACK_TEST_20261008`, 25 UTF-8 bytes.
- Working image: `NTFS_Forensic_Baseline_ADS_Slack_Working_RAW.dd`.
- Source hash matches the previously verified ADS image.
- Full comparison confirms that only the marker range changed.
- A separate read-back of 25 bytes at the documented offset returned the
  marker and matched the manifest's payload SHA-256.
- The parser still reports the original host-file metadata and the existing
  resident `CapstoneEvidence` ADS in record 58.

See [the generated manifest](w8_slack_payload_manifest.json) for all hashes
and location details. This read-back checks a known test range; it is not a
general-purpose payload discovery or recovery feature.
